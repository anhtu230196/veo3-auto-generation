# Mẫu file vòng

`THREAD.md` do `python scripts/thread.py new` sinh ra — không chép tay từ đây.

| File | Dùng cho |
| --- | --- |
| `review.md` | Lượt người review |
| `response.md` | Lượt tác giả trả lời review |

Bản đề xuất vòng 1 (`proposal`) không có mẫu cứng: nói bạn quyết định gì, chỗ nào bạn tự thấy yếu nhất, câu hỏi bạn muốn người review trả lời, và cái bạn cố ý chưa làm vì thuộc bước sau.

Quy trình đầy đủ: [`.claude/skills/deliberation/SKILL.md`](../../../.claude/skills/deliberation/SKILL.md) và [`AGENTS.md`](../../../AGENTS.md) mục 8.
